# Tesla The Fly
3D flying-car game (Three.js). Made with Aayok.

## Run in VS Code
1. Open this folder in VS Code (File > Open Folder).
2. Install the "Live Server" extension.
3. Right-click index.html > "Open with Live Server".
(You can also double-click index.html, but Live Server is smoother for audio.)

## Controls
Arrow keys: steer / accelerate / brake. Hold F to fly.
Fly over low barriers, drive under high laser gates, reach the finish gate.
